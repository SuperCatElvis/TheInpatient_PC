# The Inpatient PC — Native PC Recompilation

A planned native PC recompilation of the original The Inpatient (2018), featuring a custom Vulkan renderer, PCVR support and a flatscreen mode.

## Project Status

**Planned — Development has not yet begun.**

Development is intended to begin after the Until Dawn PC Recomp reaches a satisfactory level of stability, performance and polish.
